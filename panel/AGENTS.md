# AGENTS.md — конвенции DevBox Panel

Стек: SvelteKit 2 (Svelte 5 runes), TypeScript, Tailwind CSS 4, adapter-node.
Запуск в проде: systemd user-unit `devbox-panel.service` (см. `just panel-install` в корне окружения).

## Архитектура

- `src/lib/server/` — только серверный код (podman/env/hosts/jobs). Из endpoints дёргать его, не дублировать логику.
- `src/lib/api.ts` — типизированный клиент для фетчей; страницы не пишут `fetch` руками.
- `src/lib/components/` — переиспользуемые компоненты. Прежде чем заводить новый — посмотреть существующие.
- `src/routes/api/` — HTTP endpoints (`+server.ts`). Новые — по образцу существующих: json(), обработка ошибок → status 4xx/5xx.

## UI-правила

1. **Семантические классы + `@apply`** в `src/app.css` (`.btn-*`, `.card`, `.badge-*`, `.input`, `.terminal`, `.nav-link`).
   В них — цвета/шрифты/скругления. **Размеры, паддинги, отступы — tailwind-утилитами в разметке** (`px-3 py-2`, `text-sm` и т.п.).
2. Всё интерактивное — компоненты: `Button`, `Input`, `Select`, `Modal`, `ConfirmModal`, `StatusBadge`, `CopyField`, `LogViewer`...
   Не дублировать разметку на страницах. Иконки — только через `Icon.svelte` (lucide-пути словарём, ничего не тянем из CDN).
3. **Деструктивные/глобальные действия — только через `ConfirmModal`** с текстом последствий (пример: остановка окружения).
4. **Компактность**: информация доступна без скролла там, где возможно; техданные — `.mono`; статусы — `StatusBadge`.
5. Тёмная тема: zinc-950/900/800, акцент emerald (ok) / red (danger) / amber (warning). Без градиентов и глянца.
6. Layout: без сайдбара; шапка (лого + индикатор стека + горизонтальное меню + глобальные действия), контент `max-w-5xl`.
7. Формы: поля не должны «скакать» при вводе — динамику не выводить под полем; неподвижные суффиксы — через
   `suffix` у `Input.svelte` (абсолют внутри поля).
8. `LogViewer` — универсальный просмотрщик «источник = URL» (поддерживает `?tail=` и SSE `&follow=1`).
   Используется и для контейнеров, и для файлов из `logs/`. Новый просмотр логов делать через него.

## Известные ограничения

- Терминал в панели не реализован: нужен `node-pty` (нативный модуль), а g++ на хосте нет
  (`rpm-ostree install gcc-c++` + ребут откроет возможность). Браузер не открывает `file://` с http-страниц —
  ссылки на файловый менеджер/терминал хоста невозможны.
- Страница Logs читает только `~/Workspace/Server/logs/**` (+ journalctl панели); path-traversal закрыт в sanitize().

## Серверные правила

- Shell-команды — через `sh()` из `$lib/server/sh` (login-shell: получает PATH и DOCKER_HOST из ~/.bashrc).
- Пароли/порты читать из `.env` окружения (`readEnv()`), не хардкодить.
- Имена контейнеров валидировать (`/^server-[a-z0-9-]+$/`) перед передачей в shell.
- Долгие операции (up/build) — через jobs (`$lib/server/jobs`), опрос `GET /api/stack?id=`.

## Проверка после правок

```bash
just panel-restart   # сборка + рестарт сервиса
just panel-logs      # смотреть ошибки
```

Сборка падает на типовых ошибках Svelte/TS — это и есть проверка. Панель: http://localhost.
